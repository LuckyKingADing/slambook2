# Ch13 立体视觉里程计主要代码流程结构

## 1. 主要模块与文件结构

- app/run_kitti_stereo.cpp：主程序入口，负责数据加载、VO系统初始化与主循环。
- include/myslam/：核心类头文件，定义了各模块的接口与数据结构。
- src/：各模块实现文件。
- config/：参数配置文件。
- test/：测试代码。

## 2. 主要类与功能

### 2.1 Dataset（数据集管理）

- 负责读取KITTI等数据集的图像与位姿数据。
- 提供帧(Frame)的顺序读取接口。

### 2.2 Frame（帧）

- 表示一帧图像及其相关信息（特征点、位姿等）。

### 2.3 Feature（特征点）

- 管理图像中的特征点及其在地图点（MapPoint）中的关联。

### 2.4 MapPoint（地图点）

- 表示三维空间中的点，关联观测到该点的特征。

### 2.5 Map（地图）

- 管理所有的地图点和关键帧。

### 2.6 Camera（相机模型）

- 提供像素坐标与相机坐标、世界坐标之间的转换。

### 2.7 Config（配置管理）

- 读取和管理系统参数。

### 2.8 VisualOdometry（视觉里程计主流程）

- 管理前端（Frontend）、后端（Backend）、地图（Map）、可视化（Viewer）等模块。
- 负责整体流程的调度。

### 2.9 Frontend（前端）

- 负责特征提取、匹配、运动估计、三角化等。
- 判断关键帧，触发地图更新。

### 2.10 Backend（后端）

- 负责局部地图优化（Bundle Adjustment）。

### 2.11 Viewer（可视化）

- 实时显示轨迹、地图点等。

## 3. 主要流程结构

### 3.1 主程序流程（run_kitti_stereo.cpp）

1. 读取配置文件，初始化系统参数。
2. 创建 Dataset 实例，加载数据集。
3. 创建 VisualOdometry 实例，初始化各子模块。
4. 主循环：
   - 读取下一帧图像，构建 Frame。
   - 调用 VisualOdometry::AddFrame()，进行前端处理。
   - 可视化当前状态。
   - 判断是否结束。

### 3.2 VisualOdometry::AddFrame() 主要流程

1. 前端处理（Frontend::AddFrame）：
   - 特征提取与匹配。
   - 运动估计（位姿估计）。
   - 判断是否为关键帧。
   - 三角化新地图点。
2. 地图更新（Map）。
3. 后端优化（Backend）。
4. 可视化（Viewer）。

### 3.3 前端 Frontend::AddFrame() 主要流程

1. 如果是第一帧，初始化。
2. 对当前帧进行特征提取。
3. 立体匹配，三角化初始地图点。
4. 跟踪上一帧特征，估计当前帧位姿。
5. 判断是否插入关键帧。
6. 若插入关键帧，三角化新地图点。

### 3.4 后端 Backend::UpdateMap() 主要流程

1. 收到关键帧和新地图点后，进行局部BA优化。
2. 更新地图点和关键帧的位姿。

## 4. 主要函数结构（简要）

- main() [run_kitti_stereo.cpp]
  - Dataset::Init()
  - VisualOdometry::Init()
    - Frontend::Init()
    - Backend::Init()
    - Map::Init()
    - Viewer::Init()
  - while (Dataset::NextFrame())
    - VisualOdometry::AddFrame()
      - Frontend::AddFrame()
        - 特征提取、匹配、位姿估计、三角化
      - Map::InsertKeyFrame()
      - Backend::UpdateMap()
      - Viewer::Update()

# 主要模块与子模块调用关系（简明版）

## 总体结构

1. **主程序 main (run_kitti_stereo.cpp)**
  - 初始化配置、数据集、VO系统
  - 主循环：读取帧 → VO处理 → 可视化

2. **VisualOdometry（视觉里程计）**
  - 负责调度前端、后端、地图、可视化
  - 主要函数：`Init()`、`AddFrame()`

3. **Frontend（前端）**
  - 主要负责特征提取、匹配、位姿估计、三角化、关键帧判定
  - 主要函数：`AddFrame()`、`DetectFeatures()`、`FindFeaturesInRight()`、`EstimateCurrentPose()`、`TriangulateNewPoints()`、`InsertKeyframe()`
  - 依赖：Frame、Feature、Camera、MapPoint、Map

4. **Backend（后端）**
  - 负责局部地图优化（如BA）
  - 主要函数：`UpdateMap()`、`Optimize()`
  - 依赖：Map、MapPoint

5. **Map（地图）**
  - 管理关键帧和地图点
  - 主要函数：`InsertKeyFrame()`、`InsertMapPoint()`、`CleanMap()`
  - 依赖：Frame、MapPoint

6. **Viewer（可视化）**
  - 实时显示轨迹、地图点
  - 主要函数：`Update()`、`Close()`
  - 依赖：Map、Frame

7. **Frame/Feature/MapPoint/Camera（基础数据结构）**
  - Frame：`SetPose()`、`GetPose()`、`AddFeature()`
  - Feature：`SetMapPoint()`、`GetMapPoint()`
  - MapPoint：`SetPos()`、`AddObservation()`、`RemoveObservation()`、`GetObs()`、`CreateNewMappoint()`
  - Camera：`world2camera()`、`camera2pixel()`、`pixel2camera()`、`camera2world()`

## 主要调用链举例

```text
main
 └─ VisualOdometry::AddFrame
   ├─ Frontend::AddFrame
   │    ├─ DetectFeatures
   │    ├─ FindFeaturesInRight
   │    ├─ EstimateCurrentPose
   │    ├─ TriangulateNewPoints
   │    └─ InsertKeyframe
   ├─ Map::InsertKeyFrame / InsertMapPoint
   ├─ Backend::UpdateMap
   └─ Viewer::Update
```

## 说明

- 各模块之间通过类成员和智能指针解耦，便于扩展和维护。
- 前端与后端通过地图和关键帧/地图点进行数据交互。
- 可视化模块独立，便于实时展示系统状态。
