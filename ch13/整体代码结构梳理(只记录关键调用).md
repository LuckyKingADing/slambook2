Frontend 前端
- Frontend() 构造函数
  - 初始化特征检测器GFTTDectector
  - 配置文件读取：初始化和正常跟踪阶段的最小特征点数量（例如 50）
- AddFrame 添加关键帧
- FrontendStatus::INITING 初始化阶段
  - SteroInit 前端初始化（双目）
    - DetectFeatures 特征检测：创建掩膜mask，检测并提取左图特征点，返回特征点数量
    - FindFeaturesInRight 特征匹配： 
      - 遍历当前帧左图特征点，赋予右图特征点匹配的初始坐标：如果该特征点关联了地图点，则调用world2pixel结合双目基线外参投影到右图的像素坐标，否则，就使用左图一样的相同像素坐标作为匹配初始坐标
      - 调用opencv库函数cv::calcOpticalFlowPyrLK执行光流法计算，输出右图的特征匹配点坐标和匹配状态status
      - 结果回传，返回成功匹配的特征点数量
    - 如果找到的对应特征点数量小于初始化阶段所需的最小特征点数量，则初始化失败，返回 false
    - BuildInitMap 构建初始地图
      - triangulation(poses, points, pworld) 三角化生成地图点：传入参数包括左右相机位姿、左右相机对应的相机坐标，输出地图点三维坐标pworld
      - CreateNewMappoint 创建一个新的地图点对象及其对应id
      - SetPos 设置三角化生成的地特点的三维位置，传给成员变量
      - AddObservation 记录观测到的特征点到成员变量中
      - 将左图和右图的特征点与地图点关联
      - InsertMapPoint 地图点插入到全局地图中
        - 检查是否已经存在，不存在，则插入id和地图点；存在，则更新id和地图点
      - SetKeyFrame 设置当前帧frame为关键帧，分配并记录id
      - InsertKeyFrame 将关键帧插入到全局地图中
        - 同样分为存在和不存在两种处理方式，已存在，则更新，不存在，则插入
        - RemoveOldKeyframe 如果活跃关键帧的数量超过了预设的最大值，移除最旧的关键帧
          - 遍历活跃关键帧，统计其每个关键帧和当前关键帧的位姿距离(log().norm())
          - 设置最近距离阈值0.2m，如果min_dis小于其，则移除最近的关键帧，否则移除最远距离的关键帧
          - RemoveObservation 移除该关键帧关联的所有左图和右图特征点
          - CleanMap 遍历活跃地图点，清除地图中那些没有任何特征点观测到的地图点
      - UpdateMap 通知后端线程地图已更新，唤醒等待的线程：notify_one
    - if(build_map_success) 
      - 设置为TRACKING_GOOD状状态
      - if (viewer_) 如果可视化界面存在，则将当前帧添加到界面中，并更新地图显示
        - AddCurrentFrame
        - UpdateMap
          - assert 断言地图不为空
          - GetActiveKeyFrames 返回活跃关键帧
          - GetActiveMapPoints 返回获取激活地图点
          - true 标记地图已更新
- FrontendStatis::TRACKING_GOOD || TRACKING_BAD 正常追踪（GOOD 或 BAD状态）
  - Track 追踪阶段
    - SetPose 如果上一帧存在(更新过)，则更新当前帧的**初始化位姿**：当前帧与上一帧的相对运动（最初应该是单位矩阵）*上一帧位姿pose；第一帧的位姿通常被初始化为单位矩阵(SE3的默认值)，第一帧的位姿表示相机坐标系与世界坐标系重合；所以，如果刚好是第二帧处理，那么初始位应该姿就是单位矩阵
    - TrackLastFrame 光流LK法在当前帧中跟踪上一帧的特征点，并将成功跟踪的特征点添加到当前帧中
      - 遍历左图特征点，如果其关联了地图点，则通过world2pixel获得地图点投影到当前帧的像素位置，作为当前帧左图的初始估计位置；如果未关联地图点，则直接使用上一帧的特征点位置作为初始估计
      - calcOpticalFlowPyrLK 光流LK法根据上一帧的左图像和特征点位置得到当前帧左图像和特征点的估计位置
      - 关联上一帧的地图点到当前帧的地图点；创建当前帧特征点对象，添加到当前帧的成员函数中
    - EstimateCurrentPose 通过优化方法(g2o)估计当前帧的精确位姿
      - 设置g2o求解器：创建BlockSolverType、LinearSolverType，优化算法选择LM，线性求解器设置为Dense(稠密矩阵求解器)；SparseOptimizer是g2o的核心优化器，用于管理优化问题
      - 添加位姿顶点：
        - new VertexPose() 新建对象
        - setId 设置ID
        - setEstimate 设置顶点的初始估计值为当前帧的位姿
        - addVertex 将顶点加入优化器中
      - 获取相机内参矩阵K
      - 添加投影边：定义优化问题中的约束（特征点与地图点的投影关系）
        - 遍历当前帧的左图特征点feature_left_，如果特征点关联了地图点map_point，则创建一个一元投影边(传入地图点和K矩阵)
        - setId 设置边ID
        - setVertex(0, vertex_pose) 将当前帧的位姿顶点vertex_pose设置为边的顶点，顶点ID为0
        - setMeasurement 设置边的观测值为当前帧左图中第i个特征点的像素坐标，用于约束优化变量
        - setInformation 设置信息矩阵为单位矩阵
        - setRobustKernel 设置鲁棒核函数为Huber
        - addEdge 添加边到优化器中
      - 估计当前帧位姿，确定异常外点
        - 卡方阈值chi2_th设置为5.991
        - 迭代处理，这里设置4次
        - setEstimate 迭代开始时，将当前帧的位姿设置为优化变量的初始值
        - initializeOptimization 初始化优化器
        - optimize 最大迭代次数设置为10次，在这里已经计算了每条边的误差
        - computeError 如果该特征点被标记为异常点，则重新计算误差
        - chi2 如果误差卡方值大于阈值，则标记该特征点为异常点，设置优化等级setlever(1)
        - 卡方值正常，则设置优化等级setlever(0)
        - setRobustKernel(nullptr) 在第三次迭代时，移除鲁棒核函数，以便更精确地进行估计
      - SetPose(vertex_pose->estimate) 获取g2o优化器计算出的当前帧的最优位姿，然后更新当前帧的位姿pose
      - 清理异常点的地图点关联，如果是异常点，将特征点的地图点指针置为空 map_point.rest(H b cost置为0)，因为异常点的地图点可能是错误的；然后清除移除异常点标记，因为在后续可能会用到，可以被重新评估作为有效点，先保留
      - 返回值是除了异常外点之外的有效特征点个数，表示追踪进程中的有效特征点个数
    - FrontendStatus前端状态更新
      - 有效特征点大于num_features_tracking_(50)，标记状态为TRACKING_GOOD正常追踪
      - 有效特征点大于num_features_tracking_bad(20)，标记状态为TRACKING_BAD较差追踪
      - 否则，设置为追踪丢失LOST
    - InsertKeyframe 
      > 关键帧：构建地图和优化位姿的核心帧；用于生成和维护地图点，确保地图的准确性和稀疏性；: 后端优化（如位姿图优化）主要基于关键帧进行；只有在插入关键帧后，才有必要更新地图和后端优化器；关键帧通常是特征点分布较为丰富的帧，因此在关键帧中检测新特征点可以提高跟踪的鲁棒性；如果当前帧不是关键帧，则不会检测新特征点，因为普通帧的特征点主要用于跟踪，而不是地图扩展
      - 如果当前帧中成功跟踪到的内点数量大于num_features_needed_for_keyframe(80)，则说明当前帧的内点数量足够，认为当前帧的跟踪质量较好，不需要插入关键帧，直接返回 false，避免频繁插入关键帧，减少地图的冗余
      - SetKeyFrame 否则，标记当前帧为关键帧
      - InsertKeyFrame 当前帧插入到地图中，更新地图关键帧集合
      - SetObservationsForKeyFrame 遍历当前帧左图特征点，如果已经关联了地图点，则将该特征点添加为地图点的观测
      - DetectFeatures 特征检测并提取左图特征点
      - FindFeaturesInRight 特征匹配，在右图中找与左图匹配的特征点
      - TriangulateNewPoints 三角化生成新的地图点：对当前帧中左右图的匹配特征点进行三角化，生成新的地图点，然后将生成的地图点与特征点关联，并插入到地图中
      - UpdateMap 通知后端地图有更新
      - UpdateMap 新可视化界面的地图
    - 更新相对运动值relative_motion，表示当前帧相对于上一帧的运动(旋转+平移) relative_motion_ = current_frame_->Pose() * last_frame_->Pose().inverse()
    - AddCurrentFrame 如果启动可视化viewer，则将当前帧加入到可视化界面中去 
- FrontedStatus::LOST 追踪丢失
  - Reset 重置前端系统、重新初始化（代码尚未实现）
- 执行完switch.case.之后，更新上一帧 last_frame_ = current_frame_

Backend 后端
>  * 有单独优化线程，在Map更新时启动优化
>  * Map更新由前端触发
- Backend() 构造函数
  - 通过原子变量backend_running_控制后端线程的运行状态，设置为true表示后端线程开始运行
  - thread创建后端线程，运行BackendLoop函数
- UpdateMap 通过后端线程地图更新，唤醒线程，然后从地图中拿取激活的关键帧和地图点，执行优化
  - map_update_.notify_one() 通知
- BackendLoop 后端优化的主循环
  - backend_running_.load() backend_running为true即这一段代码为true，进入循环，开启后端线程
  - wait(lock) 阻塞在这里，等待UpdateMap()的通知
  - GetActiveKeyFrames 返回激活的关键帧
  - GetActiveMapPoints 返回激活的地图点
  - Optimize 执行优化，输入激活的关键帧Frames和激活的地图点Landmarks 
    - 设置g2o优化器相关：
      - BlockSolver_6_3  6 表示位姿变量（SE3）的自由度（3 个平移 + 3 个旋转）   3 表示地图点（3D 点）的自由度
      - LinearSolverCSparse CSparse 作为线性求解器，解决稀疏矩阵的线性方程组
      - OptimizationAlgorithmLevenberg 使用LM算法进行非线性优化
      - SparseOptimizer g2o的核心优化器，管理顶点、边、优化过程
      - setAlgorithm 传入solver，也就是传入LM算法，设置优化算法
    - 添加关键帧顶点
      - 每个关键帧的位姿被添加为一个顶点（VertexPose）
      - setId 顶点的ID设置为关键帧的 ID
      - setEstimate 设置初始估计值为关键帧的当前位姿
      - addVertex 将顶点添加进优化器
      - 持续保存当前关键帧集合中最大的关键帧ID
      - 将ID和顶点添加到顶点map中
    - 添加地图点顶点(路标顶点)
      - 如果当前路标点还没有被添加到图中(优化中)，则新加一个顶点
      - setEstimate 设置其初始估计值为路标点的三维位置
      - setId 设置顶点ID为地图点的ID加上max_kf_id + 1
      - setMarginalized 设置边缘化标志
      - insert 插入到地面路标点集合中
      - addVertex 添加到优化
      - 记录内参矩阵K和左右相机各自的外参
    - 添加边(观测)：每个边表示一个观测关系，连接一个关键帧顶点和一个地图点顶点，边的测量值为特征点的像素坐标，信息矩阵表示测量的置信度
      - 遍历路标点
      - GetObs 获取每个路标点的所有观测(也就是关联到一起的特征点)
      - 遍历观测点/特征点
      - 跳过无效的观测或标记为异常值的特征点
      - 获取观测/特征点对应的帧frame和特征点feat
      - EdgeProjection 构造边：根据特征点是否在左相机中观测到，选择使用左相机或右相机的外参构造投影边；这是改写的g2o的函数，具体要看g2o_types.h
      - 添加地图点/路标点：如果landmark还没有被加入优化，则新加一个顶点
      - 检查关键帧和路标点的顶点是否都已添加到图中，如果是，进行下面，如果不是，删除边以释放内存
      - setId 设置边ID
      - setVertex 分别将边连接到关键帧顶点(VertexPose)和路标点顶点(VertexXYZ)
      - setMeasurement 设置观测值为特征点的像素坐标
      - setInformation 设置信息矩阵
      - setRobustKernel 设置鲁棒核函数Huber，setDelta为robust kernel阈值 5.991(卡方检验阈值)，当误差小于delat时，使用二次损失函数(普通最小二乘)；当误差大于delta时，使用线性损失函数，降低异常值的影响
      - insert 添加边和特征点到std::map中
      - addEdge 添加边到优化器中
    - 执行优化
    - 剔除异常外点
      - cnt_outlier异常值外点的边数量 cnt_inlier内点的边数量
      - 迭代调整异常值阈值 5次迭代
        - 遍历所有边，根据边的误差判断是否为异常值，大于阈值chi2_th，为异常值，否则为内点
      - inlier_ratio计算内点比例，内点占内点+外点的比例
      - 如果内点比例大于 50%，停止迭代。否则，将阈值（chi2_th）加倍，并继续下一次迭代,逐步放宽异常值的判断标准，增大内点比例，放宽标准
    - 标记异常值并移除观测
    - SetPose 更新关键帧vertices的位姿Pose
    - SetPos路标点vertices_landmarks的位姿和位置Pos
